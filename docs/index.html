Lordicon Extension for Quarto

This extension lets you embed animated Lordicon icons in your Quarto HTML documents (including Reveal.js slides). Icons can be pulled from the official CDN or loaded from local .json files, and customized on the fly without editing the source files.

Showcase

Source

The {{< li >}} shortcode downloads an icon from the Lordicon CDN and renders it by its code — the eight-character identifier in https://cdn.lordicon.com/CODE.json. Lordicon used to hand these out under Export → Embed HTML; the redesigned export UI no longer offers that, so existing codes still resolve but new icons are easier to use via {{< lif >}}.

The {{< lif >}} shortcode renders an icon from a local .json file instead. Download one by opening an icon on lordicon.com, clicking Edit and download, then in the right-hand panel opening the format menu and clicking the options icon next to Lottie.

That options icon offers two Lottie flavors, and which one you want depends on where you plan to customize the icon:

  • Minified (the default) bakes the editor’s colors and stroke into the shapes and keeps only the animation you picked. Much smaller file, and the right choice when the icon already looks the way you want.
  • Raw keeps every animation along with the control layer that colors, stroke, and state write into. Choose this to customize per use from the shortcode.
Note

The two approaches don’t combine: colors, stroke, and state have no effect on a minified file, since those values were baked in at export. Either re-export as Raw or set them in the editor and leave the arguments off. The extension prints a warning when it sees that combination.

Shortcode Rendered
{{< li ibydboev >}}

{{< lif gift_raw.json >}}

Colors

colors recolors an icon. Outline icons usually have just a primary and secondary color, while flat and lineal icons can have many more. Give each color in rank:color form (ranks are primary, secondary, tertiary, …) and separate multiple colors with commas. Colors accept HTML color names or hex codes.

Shortcode Icon
{{< li rehjpyyh >}}

{{< li rehjpyyh colors=primary:gold >}}

{{< li rehjpyyh colors=secondary:gold >}}

{{< li rehjpyyh colors=primary:gray,secondary:orange >}}

{{< li rehjpyyh colors=primary:#4030e8,secondary:#ee66aa >}}

Stroke

stroke sets how thick the lines of a (supported) icon are: light, regular, or bold.

Shortcode Icon
{{< li rehjpyyh stroke=light >}}

{{< li rehjpyyh stroke=regular >}}

{{< li rehjpyyh stroke=bold >}}

Accessibility

Icons are decorative by default and hidden from assistive technology (aria-hidden="true"). When an icon carries meaning, pass a label and it is exposed to screen readers with role="img" and that name.

ARIA attributes you pass yourself take precedence. Passing a non-empty aria-hidden, aria-label, aria-labelledby, or role stops the extension from adding aria-hidden="true". With label, your own role or aria-label replaces the one label would add. When you set aria-label or aria-labelledby directly, also pass role="img" so screen readers announce the icon.

Shortcode Icon
{{< li ibydboev >}} (decorative)

{{< li ibydboev label="Money bag" >}}

{{< li ibydboev role="img" aria-label="Money bag" >}}
